Saberin Web Push 1.4.0

تغییرات نسخه 1.4.0:
- ذخیره نوع دستگاه (آیفون / اندروید / ویندوز / مک + مرورگر) برای هر اشتراک
- جدول «دستگاه‌های فعال»: هر ردیف یک دستگاه جداگانه است
- یک کاربر می‌تواند هم‌زمان چند دستگاه داشته باشد (لپ‌تاپ + گوشی + ...)
- ارسال به: همه / دستگاه‌های انتخاب‌شده / کاربران انتخاب‌شده
- حذف دستی هر دستگاه از پیشخوان
- راهنمای آیفون (نیاز به Add to Home Screen از iOS 16.4+)

نیازمندی‌ها:
- PHP 7.3+ با openssl_pkey_derive
- افزونه Saberin PWA نسخه 1.3.0+
- HTTPS
